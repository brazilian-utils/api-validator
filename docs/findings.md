# Findings from the first full run (2026-09-22)

Produced by `api-validator check --tests` and `api-validator diff` against the default
branch of every lib (JS `ce2df9c`, Python `330627e`, Go `ea155a8`, Rust `a60585f`,
Ruby `a54d408`, Erlang `48dd38d`, .NET `8d8846d`). Runners exist for TS, Python, Go, Rust
and Ruby; Erlang and .NET are checked for API only.

`diff` compared 730 calls (same mined input, every lib) and found 216 divergent inputs in
31 functions. They fall in two groups.

## Bugs (encoded as contract tests, failing where they apply)

| Vector | Expected | Libs that disagree | Evidence |
|---|---|---|---|
| `pis.isValid("00000000000")`, `("99999999999")` | `false` | Go, Python, Ruby, Rust return `true` | A PIS of one repeated digit is reserved; the same rule holds for CPF/CNPJ, where every lib already agrees |
| `cnh.isValid("75206264506")` | `true` | Python returns `false` | Go, JS, Ruby, Rust agree. Python implements the 2022 CNH algorithm (`brutils/cnh.py`), so this may be a spec question rather than a bug: confirm and adjust the vector |

## Decisions needed (not encoded yet — pick one answer, add the vector)

Each row is a behaviour where the libs split into camps. Once decided, add the vector to
the contract; the losing libs get it in their `api-contract` issue.

| # | Question | Camp A | Camp B | Example |
|---|---|---|---|---|
| 1 | Does `isValid` accept masked input (`821.785.374-64`, `01310-200`, `1590 5961 28 52`)? | JS, Go: yes | Python, Ruby, Rust: no (digits only) | `cpf`, `cnpj`, `cep`, `pis`, `voterId` |
| 2 | What does `format` return for an invalid/incomplete value? | JS, Go: formats anyway (`"123"` → `"123"`, invalid check digit still formatted) | Python, Ruby, Rust: `null` | `cpf`, `cnpj`, `cep`, `pis`, `voterId`, `legalProcess` |
| 3 | `format("")` / garbage | JS, Go: `""` | Python, Ruby, Rust: `null` | same as above |
| 4 | Default phone mask | JS: `"98765-4321"` (no area code unless `mask: "auto"`) | Go, Python, Ruby, Rust: `"(11)99402-9275"` (no space) | `phone.format` |
| 5 | Converting a plate that is already Mercosul | JS, Go: `""` | Python, Ruby, Rust: `null` | `licensePlate.convertToMercosul` |
| 6 | Unknown legal nature code | Go: `""` | Python, Ruby, Rust: `null` | `legalNature.getDescription` |
| 7 | Legal process numbers generated by JS (year 2026) | JS: valid | Go, Python, Ruby, Rust: invalid | `legalProcess.isValid` — check segment/tribunal rules |
| 8 | Lowercase passport (`"lh961596"`) | JS: valid | Python: invalid | `passport.isValid` |
| 9 | Empty/garbage input to `currency.format` / `date.convertToWords` | JS: `"0,00"` / `""` | Python, Ruby: `null` | |

The API itself also diverges in shape; the lib reports list every case. Most common:
`isValid`/`format` taking an options object in JS only (`does not support optional
parameter "options"`), `generate` taking a required argument in Go/Rust (`cnpj.Generate(branch)`),
`isHoliday`/`getCepInfoByAddress` taking an object in JS and positional args elsewhere,
and `format` returning `string?` in Python/Ruby/Rust vs `string` in the contract (a
consequence of decision 2).
