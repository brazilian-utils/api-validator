## What is Brazilian Utils?

A set of libraries for the data every Brazilian system handles: CPF, CNPJ, CEP, license plates, phone numbers, boletos and more. They validate, format, parse and generate that data. There is one library for each of seven languages: JavaScript, Python, Go, Ruby, Rust, .NET and Erlang. All of them follow one [shared contract](/contributing/specs/), so a CPF that is valid in one language is valid in all of them.

## How did it start?

Hyan Mandian started Brazilian Utils in June 2018 as a personal project: a JavaScript library for Brazilian data. Contributors brought it to other languages, and the project became an organization.

- **2018.** The JavaScript library, then Go and Rust (Andreo Vieira) and .NET (Rodinei Fagundes).
- **Older libraries.** Two libraries are older than the organization and joined it: the Ruby gem, started by Alex Rocha in 2016, and the Python library, started by Luiz Berti in 2017 as brutils.
- **2023.** The Python library grew with [Cumbuca Dev](https://github.com/cumbucadev), a community that teaches programming through open source.
- **2025.** Brazilian Utils partnered with Cumbuca Dev, and the two joined forces ([the conversation that started it](https://github.com/brazilian-utils/python/issues/461)).
- **2025 and 2026.** Leonel Sanches da Silva brought the Go, Ruby, Rust and .NET libraries up to date, and Camilo Cunha de Azevedo wrote the Erlang library.
- **2026.** The shared contract, the tests every library runs and this site.

The people behind each library are on the [Team](/about/team/) page.

## Why is the logo a caramelo dog?

The caramelo is the Brazilian street dog: a mixed-breed dog with a caramel coat, found on streets, in shops and in homes all over the country. It became an unofficial national symbol. When the Central Bank announced a R$ 200 note in 2020, many people asked for the caramelo to be on it.

A project that handles the everyday details of Brazil took the most Brazilian dog there is. [Read more about the caramelo](https://en.wikipedia.org/wiki/Caramelo_(dog)).

## Are the libraries free to use?

Yes. Every library is open source under the MIT license, commercial use included.

## Do all libraries do the same thing?

They aim to. The contract lists every function and its test cases, and each library runs those cases in its own test suite. Libraries are at different stages, so some functions are still missing in some languages. The [parity matrix](/reference/parity/) shows what each library has today, and each utility page shows it per function.

## My language is not on the list

A new library can start small: a few functions, with the shared tests running from day one. [Add a language](/contributing/new-language/) explains the steps.

## Do the libraries send my data anywhere?

No. They run inside your program. The only exception is the address lookup by CEP (`getAddressInfoByCep` and its equivalents), which asks public CEP services over the internet. The [privacy](/about/privacy/) page covers this site.

## Where do I report a bug or ask a question?

In the repository of the library: its issues for bugs, its discussions for questions. The [community guide](/about/community-guide/) lists where each thing goes. Report a security problem in private, as the library's `SECURITY.md` says, or by e-mail to support@brazilian-utils.com.br.
