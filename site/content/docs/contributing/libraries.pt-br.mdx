Cada biblioteca é um repositório próprio, escrito do jeito que a linguagem espera, pelas pessoas que a usam ali. Uma mudança no que uma função faz começa no contrato compartilhado; todo o resto (um bug numa biblioteca, o código, os testes, o release) começa no repositório dela, seguindo o guia de contribuição dela.

## O que vai para onde

- **Uma função que a biblioteca não tem, ou um caso em que ela falha.** A lacuna já aparece na página da biblioteca e, em geral, como uma issue no repositório dela, com o código de referência. [Preencher uma lacuna numa biblioteca](/pt-br/contributing/new-language/) mostra o caminho.
- **Uma mudança no que uma função faz**, em todas as bibliotecas de uma vez: uma regra nova, um caso novo, uma função nova. Isso é uma mudança no contrato: [Mudar o contrato](/pt-br/contributing/specs/).
- **Uma biblioteca numa linguagem nova.** [Começar uma biblioteca numa linguagem nova](/pt-br/contributing/new-language/#comece-uma-biblioteca-numa-linguagem-nova).
- **O exemplo de uma biblioteca neste site.** Os exemplos vêm dos arquivos `docs/usage/` da própria biblioteca: [Arquivos de uso](/pt-br/contributing/usage-files/).
