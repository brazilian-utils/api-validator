Brazilian Utils is a set of libraries that validate, format and generate Brazilian data: CPF, CNPJ, CEP, license plates, phone numbers, boletos and more. There is one library for each language. The [brazilian-utils](https://github.com/brazilian-utils) organization maintains them, and this site documents them in one place.

## Read a utility page

Each utility has one page for all languages. Each page has the same parts, in this order:

1. **The libraries.** How many functions of the utility each library implements.
2. **One section for each function**, such as validate, format or generate. Each section shows:
   - the signature from the contract and its parameters,
   - which libraries implement the function and whether they pass all shared test cases,
   - a tab for each library, with an example in that language,
   - a "Try it" box that runs the JavaScript library in your browser,
   - the shared test cases, with the result in each library.
3. **The specification.** What the identifier is, its format, the algorithm and the regular expressions. Some utilities have this long text, others have only a summary.
4. **Official sources.** The law, decree or government document that defines the rule.

Pick your language (JavaScript, Python, Go, Ruby, Rust, .NET or Erlang) in any tab. Every page then opens on that language.

All libraries behave the same because the shared contract defines the behavior, and the test cases check it. The contract lives in [api-validator](https://github.com/brazilian-utils/api-validator). No single library defines it.

Select your language on the [home page](/) to see the install command, or go to the package registry:

| Language | Package | Repository |
| --- | --- | --- |
| JavaScript / TypeScript | [`@brazilian-utils/brazilian-utils`](https://www.npmjs.com/package/@brazilian-utils/brazilian-utils) | [javascript](https://github.com/brazilian-utils/javascript) |

## What the libraries do not do

The libraries check the **structure** of a value: its length, its characters and its check digits. They do not query government databases. A valid CPF or CNPJ is a well-formed number. It does not mean that the person or the company exists. A function that calls an external service, such as the address lookup by CEP, says so in its section.
