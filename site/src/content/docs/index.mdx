## Libraries

Each library has the same functions, with names in the style of its language. Select a language in a usage tab once. The site keeps that tab open on every page.

<LibTable />

## How the libraries stay the same

<ol class="flow">
  <li><strong>Contract</strong> A new function goes into the contract first, with its test cases.</li>
  <li><strong>Issues</strong> Each library that does not have the function gets an issue.</li>
  <li><strong>Tests</strong> Each library runs the shared test cases with its own test command.</li>
  <li><strong>This site</strong> It shows the contract, an example from each library and the last test results.</li>
</ol>

The site opens in Portuguese when your browser prefers it. The language menu changes it, and the site keeps your choice.

Start with [getting started](/getting-started/), compare the libraries in the [parity matrix](/reference/parity/), or [add a function to the contract](/contributing/specs/).
