Seven libraries validate, format and generate Brazilian documents: CPF, CNPJ, CEP, license plates, boletos and more. One contract defines each function and its test cases. This site shows the contract and how each library follows it.

<Specimen />

## Libraries

Each library has the same functions, with names in the style of its language. Select a language in a usage tab once. The site keeps that tab open on every page.

<LibTable />

## How the site stays correct

1. A new function goes into the contract first, with its test cases.
2. Each library that does not have the function gets an issue.
3. Each library runs the shared test cases with its own test command.
4. The site shows the contract, an example from each library and the result of the last test run.

The site opens in Portuguese when your browser prefers it. The language menu changes it, and the site keeps your choice.

Start with [getting started](/getting-started/), compare the libraries in the [parity matrix](/reference/parity/), or [add a function to the contract](/contributing/specs/).
