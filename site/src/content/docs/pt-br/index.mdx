## Bibliotecas

Todas as bibliotecas têm as mesmas funções, com nomes no estilo de cada linguagem. Escolha a linguagem uma vez numa aba de uso. O site mantém essa aba aberta em todas as páginas.

<LibTable />

## Como as bibliotecas continuam iguais

<ol class="flow">
  <li><strong>Contrato</strong> Uma função nova entra primeiro no contrato, com os casos de teste.</li>
  <li><strong>Issues</strong> Cada biblioteca que não tem a função recebe uma issue.</li>
  <li><strong>Testes</strong> Cada biblioteca roda os casos de teste compartilhados com o próprio comando de teste.</li>
  <li><strong>Este site</strong> Mostra o contrato, um exemplo de cada biblioteca e os últimos resultados dos testes.</li>
</ol>

O site abre em português quando o navegador prefere português. O menu de idioma muda isso, e o site guarda a sua escolha.

Comece por [primeiros passos](/pt-br/getting-started/), compare as bibliotecas na [matriz de paridade](/pt-br/reference/parity/) ou [adicione uma função ao contrato](/pt-br/contributing/specs/).
