Sete bibliotecas validam, formatam e geram documentos brasileiros: CPF, CNPJ, CEP, placas, boletos e outros. Um contrato define cada função e os casos de teste dela. Este site mostra o contrato e como cada biblioteca o segue.

<Specimen />

## Bibliotecas

Todas as bibliotecas têm as mesmas funções, com nomes no estilo de cada linguagem. Escolha a linguagem uma vez numa aba de uso. O site mantém essa aba aberta em todas as páginas.

<LibTable />

## Como o site continua correto

1. Uma função nova entra primeiro no contrato, com os casos de teste.
2. Cada biblioteca que não tem a função recebe uma issue.
3. Cada biblioteca roda os casos de teste compartilhados com o próprio comando de teste.
4. O site mostra o contrato, um exemplo de cada biblioteca e o resultado da última execução dos testes.

O site abre em português quando o navegador prefere português. O menu de idioma muda isso, e o site guarda a sua escolha.

Comece por [primeiros passos](/pt-br/getting-started/), compare as bibliotecas na [matriz de paridade](/pt-br/reference/parity/) ou [adicione uma função ao contrato](/pt-br/contributing/specs/).
