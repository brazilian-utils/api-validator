Cada célula conta quantas operações do utilitário a biblioteca implementa: ● todas, passando em todos os casos compartilhados; ◐ algumas; ✕ ao menos uma falha num caso; ○ nenhuma. Passe o mouse sobre uma célula para ver as operações uma a uma, ou abra a página de uma biblioteca para os detalhes.
